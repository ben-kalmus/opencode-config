## Quick start

Symlink to opencode directory with stow:

```sh
stow -t ~ opencode
``` 

## Prereq

Add a key to your environment variables:

```sh
#.env
export OPENROUTER_API_KEY=...

```

Enable web search in opencode:
 
```sh 
# .zshrc / .bashrc
export OPENCODE_ENABLE_EXA=1 
```
